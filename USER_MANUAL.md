# User Manual

## 1. Login and Access

1. Open the frontend URL.
2. Register or login with your credentials.
3. After login, open `Dashboard`.

## 2. Submit a Complaint

1. Open `My Complaints` -> `New Complaint`.
2. Fill title, category, priority, and description.
3. Attach files if needed.
4. Submit and note the complaint ID.

## 3. Track Complaint Status

- Open `My Complaints` to view current status.
- Click a complaint to see full details, timeline, and attachments.

## 4. Resolution and Feedback

- When complaint status is `resolved`, open complaint details.
- Provide rating and comments in the feedback form.

## 5. Common Statuses

- `new`: Created and awaiting assignment
- `assigned`: Assigned to staff
- `in-progress`: Active investigation/work
- `resolved`: Marked solved by staff
- `escalated`: Raised to higher priority/level
- `closed`: Finalized

## 6. Troubleshooting

- If session expires, login again.
- If file upload fails, reduce size and retry.
- For urgent issues, contact support/admin directly.
